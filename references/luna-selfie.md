# 角色自拍参考文档

## history.json（去重用，agent 维护）

路径：`~/.hermes/selfie/history.json`

**仅用于去重，不用于调度轮换。** agent 自由发挥场景/穿搭/饰品，生成后追加记录。发车前查最近 7 天是否重复。

```json
[
  {
    "date": "2026-05-25",
    "scene": "海边日出",
    "outfit": "蓝白修身短袖衬衫+黑色百褶短裙+白色中筒袜",
    "accessories": "蝴蝶发卡"
  }
]
```

- 每次生成后追加一条
- 保留最近 30 天记录
- 检查重复以**场景 + 穿搭**为主

## 提示词结构建议

agent 自由构思时，可以从以下维度组织场景 prompt：

1. **场景设定**：地点、时间、环境（海边/咖啡厅/办公室/居家……）
2. **服装造型**：衣着、发型、鞋袜
3. **配饰**：发卡、项链、手链等
4. **动作表情**：神情、姿势、情绪
5. **拍摄风格**：视角、光线、色调

## 支持的分辨率

| 分辨率 | 比例 | 适用场景 |
|--------|------|----------|
| 1280*1280 | 1:1 | 通用、头像（默认） |
| 720*1280 | 9:16 | 自拍、全身照、手机壁纸（推荐） |
| 853*1280 | 2:3 | 半身照、竖版构图 |
| 1024*1536 | 2:3 | 竖版人像 |
| 1080*1920 | 9:16 | 全高清竖版 |
| 1280*720 | 16:9 | 横版场景 |
| 1280*853 | 3:2 | 横版人像 |
| 1536*1024 | 3:2 | 横版场景 |
| 1920*1080 | 16:9 | 全高清横版 |
| 2048*2048 | 1:1 | 超高清正方形 |

所有分辨率都是 16 的倍数，符合百炼 API 要求。

## WAN 2.7 手臂/手部连接缺陷

WAN 2.7 模型在生成半身自拍时，**经常生成手部但缺少完整的手臂连接**。这是已知模型缺陷。

缓解策略已内置在 `config.json` 的 `quality_fixes` 中，出厂自带手臂完整性修复提示词。如果生成后仍有问题：

- 选择让手臂完全暴露的 pose（举过头顶、自然下垂）
- 避免长袖遮挡手腕
- **必须人工肉眼检查**，不可依赖 AI 视觉分析

详细说明见 `references/wan27-arm-hand-connection-issue.md`。

## 故障排除

### 请求失败
- 检查 `.env` 中的 `SELFIE_API_KEY` 是否正确
- 确认网络连接正常
- 检查百炼 API 额度是否充足

### 参考图加载失败
- 检查 `config.json` 中 `reference_image` 路径是否正确
- 确认图片文件存在且可读
- 支持 JPG、PNG、WebP 格式

### 角色不一致
- 使用清晰的正面或半侧面人像作为参考图
- 配置 `config.json` 中 `character` 描述身高/身材/面型
- 确保参考图光线均匀、面部无遮挡
