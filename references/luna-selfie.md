# agent 角色自拍生成器 (luna-selfie)

agent 角色的专属自拍技能，基于阿里云百炼 WAN 2.7 图生图 API，支持角色一致性保持。

## 🌟 特性

- ✅ **角色一致性**：使用参考图保持 agent 角色形象一致
- ⚡ **异步生成**：支持任务轮询，自动等待完成
- 🎨 **多分辨率**：支持多种尺寸选择
- 📸 **自拍视角**：优化的自拍视角和摄影风格

## 📦 安装

本 skill 应安装在以下位置：
- **Hermes**: `~/.hermes/skills/luna-selfie/`

## 🔑 配置

### 1. API Key

API Key 配置在 `~/.hermes/.env` 文件中：

```bash
SELFIE_API_KEY=sk-xxxxxxxxxxxxxxxx
```

### 2. 角色参考图

在 `~/.hermes/.env` 文件中配置露娜的标准形象图本地路径：

```bash
REF_IMAGE_PATH=<HOME>/.hermes/avatars/luna_standard.jpg
```

### 3. 默认输出目录

Hermes: `~/.hermes/selfie/`

文件名格式：`luna_selfie_YYYYMMDD_HHMMSS.png`


**说明**：
- 参考图用于保持角色面部特征和身材的一致性
- 使用本地图片路径，脚本会自动转成 base64
- 如不配置，将使用纯文生图模式

## 🛠️ 使用步骤

- [] step 1：自拍
  - 调用 `generate_selfie.py` 脚本，传入提示词和分辨率，生成自拍图片
  - 提示词带上 24岁，身材苗条
  - 场景：自由发挥（办公室、咖啡厅、健身房、公园、约会、居家等）
  - 动作表情：自由发挥（姿势、神情、情绪等）
  - 服装造型：自由发挥（衣着、发型、鞋袜、妆容、配饰等）
  - 拍摄风格：自由发挥（视角、光线、色调、全身、半身等）
  - 分辨率：竖拍使用 `720*1280`，横拍使用 `1280*853`

- [] step 2：发送自拍照
  - 使用 `lark-cli im +messages-send` 发送图片和文字问候
  - **注意**：`--image` 与 `--text`/`--markdown` 互斥，图片和文字需分两条消息发送
  - **路径限制**：`--image` 必须使用相对路径且需 `cd` 到图片所在目录，否则报错 `--file must be a relative path within the current directory`
  - 发送示例：
    ```bash
    cd <HOME>/.hermes/selfie
    lark-cli im +messages-send --chat-id $FEISHU_HOME_CHANNEL --image ./luna_selfie_YYYYMMDD_HHMMSS.png --as bot
    lark-cli im +messages-send --chat-id $FEISHU_HOME_CHANNEL --text "早安呀～今天阳光很好呢 ☀️" --as bot
    ```

## 🚀 脚本使用方法

### 基础用法

```bash
cd ~/.hermes/skills/luna-selfie
python3 scripts/generate_selfie.py "咖啡厅窗边，手捧咖啡，文艺氛围"
```

### 指定分辨率

```bash
# 竖版自拍（推荐）
python3 scripts/generate_selfie.py "阳台夜景" --size 720*1280

# 正方形（默认）
python3 scripts/generate_selfie.py "办公室" --size 1280*1280

# 全高清竖版
python3 scripts/generate_selfie.py "咖啡厅" --size 1080*1920
```

## 📊 支持的分辨率

| 分辨率 | 比例 | 适用场景 |
|--------|------|----------|
| 1280*1280 | 1:1 | 通用、头像（默认） |
| 720*1280 | 9:16 | 自拍、全身照、手机壁纸（推荐） |
| 853*1280 | 2:3 | 半身照、竖版构图 |
| 1024*1536 | 2:3 | 竖版人像 |
| 1080*1920 | 9:16 | 全高清竖版、手机壁纸 |
| 1280*720 | 16:9 | 横版场景、电脑壁纸 |
| 1280*853 | 3:2 | 横版人像 |
| 1536*1024 | 3:2 | 横版场景 |
| 1920*1080 | 16:9 | 全高清横版、电脑壁纸 |
| 2048*2048 | 1:1 | 超高清正方形 |

**注意**：所有分辨率都是 16 的倍数，符合百炼 API 要求。

## 🤖 自动化 / Cron 任务自拍

当自拍作为定时任务（cron job）运行时，**必须遵守以下铁律**：

1. **必须生成真实图片**：调用 `generate_selfie.py` 脚本，产出实际的 `.png` 文件
2. **禁止发送文字描述替代**：不能仅发送"我在阳台伸懒腰"等文字描述代替真实照片
3. **必须通过 MEDIA: 标签交付**：在最终回复中包含 `MEDIA:/path/to/image.png`
4. **提示词必须包含固定特征**：`24岁，身材苗条`
5. **失败后立即停止**：如遇 API 429 / 500 / 额度不足，**立即停止，不重试**，用文字报告失败

**当前 cron 配置**（每天 8:05 自拍）：
- **任务名**：agent 角色自拍 - 每天8:05
- **schedule**：`5 8 * * *`
- **执行命令**：
  ```bash
  cd <HOME>/.hermes/skills/luna-selfie && python3 scripts/generate_selfie.py "[提示词]" --size 720*1280
  ```
- **输出路径**：`<HOME>/.hermes/selfie/luna_selfie_YYYYMMDD_HHMMSS.png`
- **参考图**：`<HOME>/.hermes/avatars/luna_standard.png`

**典型错误**：cron job prompt 只要求"发送早安问候并描述自拍场景"，导致只输出文字而没有调用脚本生成图片。

## ⚠️ 注意事项

1. **参考图要求**：使用清晰的正面或半侧面人像（本地路径）
2. **使用频率**：合理使用，避免触发 API 限流
3. **图片格式**：支持 JPG、PNG、WebP 格式

## 🐛 故障排除

### 问题：请求失败

**解决方案**：
1. 检查 API Key 是否正确
2. 确认网络连接正常
3. 检查 API 额度是否充足

### 问题：参考图加载失败

**解决方案**：
1. 检查文件路径是否正确
2. 确认图片文件存在且可读
3. 检查图片格式是否支持

### 问题：角色不一致

**解决方案**：
1. 使用清晰的参考图
2. 在提示词中强调角色特征
3. 确保参考图是正面或半侧面人像
