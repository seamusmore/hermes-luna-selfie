# WAN 2.7 手臂/手部连接缺陷参考

## 问题现象

WAN 2.7 模型在生成半身自拍时，**经常生成手部但缺少完整的手臂连接**。手看起来像是"悬浮"在身体旁边，没有从肩膀→手肘→手指的自然延伸。这是该模型的已知缺陷。

## 典型翻车场景

| 场景 | 翻车率 | 原因 |
|------|--------|------|
| 长袖+手持手机 | ~90% | 袖子遮手腕+手机遮手掌，连接处完全不可见 |
| 托腮/托下巴 | ~70% | 手腕被遮挡，模型无法正确生成前臂 |
| 双手抱胸 | ~60% | 手臂交叉，连接处复杂 |
| 双手举过头顶 | ~20% | 手臂完全可见，但模型可能省略上臂 |
| 双手自然下垂 | ~30% | 相对安全，但仍可能缺少前臂 |

### 缓解策略

**1. 提示词中必须明确手臂完整性**
```
完整的双臂从肩膀到手肘到手指连贯自然，
双手清晰可见，手臂比例正常
```

**2. 优先选择让手臂完全暴露的 pose**
- ✅ 双手举过头顶（双臂完全可见）
- ✅ 双手放在身体两侧
- ✅ 双手自然下垂
- ❌ 长袖+手持手机（袖子遮手腕，手机遮手掌）
- ❌ 托腮/托下巴（手腕被遮挡，连接处易断裂）
- ❌ 双手抱胸（手臂交叉，连接处复杂）

**3. 避免长袖衣服遮挡手腕**
如果穿长袖，在提示词中明确：
```
短袖或七分袖，手腕和手指完全可见
```

**4. 生成后质量检查**
- ⚠️ **不要依赖 vision_analyze 工具检查手部质量** — vision 工具也会幻觉，会报告"手臂自然连接"即使实际上没有
- 应该用肉眼仔细检查：手是否真的长在胳膊上？肩膀→手肘→手指的过渡是否自然？
- 如果不确定，宁可重新生成

**质量检查必须人工肉眼确认**，不能依赖 AI 视觉分析。
